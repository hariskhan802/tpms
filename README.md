# TPMS Mobile App

## Overview

**TPMS (Tire Pressure Monitoring System)** is a cutting-edge mobile application built on React Native. It is designed to provide real-time monitoring of tire pressure and temperature, ensuring the safety and efficiency of vehicle operation. The app seamlessly integrates with IoT devices, offering a user-friendly interface and robust performance.

---

## Key Features

- **Real-Time Monitoring**: Displays live tire pressure and temperature data.
- **Alerts & Notifications**: Instant notifications for abnormal pressure or temperature readings.
- **User-Friendly Interface**: Intuitive design for effortless navigation.
- **Cross-Platform Compatibility**: Runs flawlessly on both iOS and Android devices.
- **Bluetooth Integration**: Connects seamlessly with IoT sensors.
- **Customizable Settings**: Users can personalize thresholds and preferences.
- **Secure Data Handling**: Ensures secure communication between the app and IoT devices.

---

## Technical Highlights

- **React Native**: Leveraged for building a high-performance, cross-platform mobile app.
- **State Management**: Implemented using Redux for predictable and maintainable state.
- **TypeScript**: Ensures type safety and reduces runtime errors.
- **Real-Time Updates**: Utilized WebSocket and BLE (Bluetooth Low Energy) for live data streaming.
- **Modular Architecture**: Clean and scalable code structure following best practices.
- **Third-Party Libraries**: Integrated libraries like `react-native-ble-manager` for Bluetooth functionality and `react-navigation` for seamless navigation.
- **CI/CD Pipeline**: Automated build, testing, and deployment using GitHub Actions.

## Installation

Follow these steps to set up the TPMS app on your local machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/hariskhan802/tpms](https://github.com/hariskhan802/tpms.git)
   ```
2. **Navigate to the project directory:**
   ```bash
   cd tpms
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run the app:**
   - For iOS:
     ```bash
     npx pod-install && npm run ios
     ```
   - For Android:
     ```bash
     npm run android
     ```
